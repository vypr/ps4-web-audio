# PS4 Web Audio — v1.1.0 (Simple Controls)

Includes the full No Background source, native PS4 user interface, controller-button symbols, browser client, audio payload, and OpenOrbis build scripts.

**Installable PKG is a separate release asset** (`PS4-Web-Audio-No-BG.pkg`). The PKG compiled on the maintainer's WSL machine is not included in this source archive.

Run `bash test_project.sh` and `bash build_pkg.sh` from this directory after configuring the full OpenOrbis SDK. See README.md.
